# WordPress Plugin Downloader

Um plugin WordPress simples que permite fazer download de múltiplos plugins instalados em formato ZIP.

## 🚀 Funcionalidades

- Lista todos os plugins instalados no WordPress
- Permite seleção múltipla de plugins
- Botão "Selecionar todos" para facilitar a seleção
- Gera arquivo ZIP mantendo a estrutura de pastas original
- Download automático do arquivo ZIP gerado
- Interface integrada ao padrão WordPress

## 📦 Instalação

1. Faça o download do arquivo `plugin-downloader.php`
2. Faça upload para a pasta `wp-content/plugins/` do seu WordPress
3. Ative o plugin através do menu 'Plugins' no WordPress
4. Acesse através do menu Plugins > Download Plugins

## 🛠️ Como Usar

1. Acesse o menu "Download Plugins" no painel administrativo
2. Selecione os plugins que deseja baixar
3. Clique no botão "Download Selected Plugins"
4. O arquivo ZIP será gerado automaticamente com os plugins selecionados

## 💻 Requisitos

- WordPress 5.0 ou superior
- PHP 7.2 ou superior
- Permissões de escrita no diretório temporário do servidor
